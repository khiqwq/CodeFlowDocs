# 接入凭证：Base URL、令牌与分组

接入任何工具都需要两项信息：**接入地址（Base URL）** 与 **API 令牌**；创建令牌时还需选择分组，分组决定可调用的模型范围与计费倍率。这三项对所有客户端通用，本页集中说明

## Base URL

将客户端原有的模型服务地址（例如 `https://api.anthropic.com`）替换为 {{SITE_NAME}} 的接入地址，客户端即通过 {{SITE_NAME}} 调用相应模型。接入地址在控制台 **令牌管理** 页面下方的「API 接入地址」区域获取，支持一键复制

![令牌管理与 API 接入地址](/assets/images/access/token-management-api-endpoint.png)

```text
{{SITE_URL}}
{{SITE_URL}}/v1
```

两条线路的账号、令牌与余额通用，可随时切换。各客户端要求的地址形态不同：

|客户端|接入地址|
|---|---|
|Claude Code|`{{SITE_URL}}`，不带 `/v1`|
|Codex|`{{SITE_URL}}/v1`|
|CC Switch|Claude 模板不带 `/v1`，Codex 模板带 `/v1`|
|Cherry Studio|Anthropic 提供商不带 `/v1`，OpenAI 提供商带 `/v1`|
|Kilo Code|`{{SITE_URL}}/v1`|
|OpenCode|`{{SITE_URL}}/v1`|
|OpenClaw|`{{SITE_URL}}`，不带 `/v1`|

> **注意**
> 不要按协议类型推断地址形态。例如 OpenCode 使用 Anthropic SDK，但其 `baseURL` 仍需包含 `/v1`。填写时以各客户端页给出的形式为准

## API 令牌

令牌在 **令牌管理 → 创建令牌** 中生成

![创建令牌](/assets/images/access/create-token.png)

创建对话框含三个字段：

|字段|说明|
|---|---|
|名称|用于区分令牌用途。建议按客户端命名，例如 `claude-code`、`codex`，便于核对用量|
|分组|决定可调用的模型范围和计费倍率，详见下文「分组与计费倍率」|
|费用限制|该令牌允许累计消费的最高金额，单位为美元。达到上限后，该令牌的请求将被拒绝；其他令牌和账户余额不受影响。留空表示不设置此项限制|

费用限制约束的是累计总额，非每日额度；达到上限后在列表中调高即可，无需重建令牌。令牌不设有效期，也不提供模型或 IP 限制，费用限制因此是令牌层面唯一的止损手段

> **注意**
> 令牌仅在创建时完整显示一次，请立即复制并妥善保存。列表中的「密钥」字段会隐藏部分内容，无法用于恢复完整令牌。令牌丢失后，删除原令牌并重新创建即可

### 令牌保管

- 不要将令牌提交到 Git 仓库。各客户端页的示例优先使用用户级配置文件；如确需使用项目级配置，请确认相关文件已加入 `.gitignore`
- 不要将令牌以明文写入团队模板、Docker 镜像、公开日志或会同步到 dotfiles 仓库的文件。CI/CD 场景应使用平台提供的加密 Secret，不要写入普通变量或仓库文件
- 提交日志、截图或 issue 前先脱敏，终端回显与报错信息中亦可能包含令牌
- 疑似泄露时，在 **令牌管理** 中删除并重新创建，填回工具即可，原令牌立即失效，不影响余额与订阅
- 为每个令牌设置「费用限制」，控制单个令牌的最大损失

## 分组与计费倍率

> **数据来源与核验**
> - **来源**：[{{SITE_NAME}} 控制台「令牌管理」]({{SITE_URL}}/tokens)的创建令牌分组选项
> - **核验范围**：分组名称与计费倍率
> - **最后核验日期**：2026 年 8 月 18 日

创建令牌时选择的分组决定可调用的模型范围、平台采用的服务线路以及计费倍率。实际计费金额为模型单价乘以对应分组倍率

|分组|说明|可调用模型|计费倍率|
|---|---|---|---|
|Claude 低价分组|平台标注为 Kiro 线路|Claude 系列（`claude-*`）|×1|
|Codex 官方分组|平台标注为 Codex 官方线路|GPT 系列（`gpt-*`）|×1|
|Claude 稳定分组|平台标注为混合线路|Claude 系列（`claude-*`）|×3|
|Claude 官方分组|平台标注为 Claude 官方线路|Claude 系列（`claude-*`）|×9|

表中的线路说明来自控制台，用于区分平台提供的服务分组，不构成对具体上游实现的独立保证。线路名称、可用模型和倍率均可能调整，创建令牌时请以控制台实时显示为准

选择建议：

|使用场景|建议分组|
|---|---|
|优先考虑较低倍率|Claude 低价分组（×1）|
|需要平台标注的混合线路|Claude 稳定分组（×3）|
|需要平台标注的官方线路|Claude 官方分组（×9）|
|Codex／GPT 系列|Codex 官方分组（×1）|

> **注意**
> 令牌分组必须与模型系列匹配：`claude-*` 模型对应 Claude 系列分组，`gpt-*` 模型对应 Codex 官方分组。分组不匹配时，请求通常会返回模型不可用或类似错误。需要同时使用两类模型时，请分别创建令牌
